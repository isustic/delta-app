# Delta application audit — 22 October 2026

## Fixes

- Excel export no longer loops indefinitely when two agent names share their first 31 characters. Sheet names are unique without regard to case, reserve space for numeric suffixes, and strip invalid leading/trailing apostrophes.
- Product and client imports validate their headers and reject empty replacement datasets. Invalid imports preserve existing records.
- Startup seeds both reference tables in one transaction. Missing or invalid resources fail explicitly, roll back partial imports, and are not recorded as a successful seed.
- Product and client mutations refresh rows, pagination, and filter options. Previously deleting all records left the old table visible, and adding from a later page could show first-page rows with a later-page offset.
- Responses from an old table query are invalidated as soon as search/filter changes begin, before the debounce completes. Unmount invalidates pending responses as well.
- Reports validate source column headers and reject invalid/nonfinite accounting amounts with a year and row number instead of silently omitting the transaction.
- Report years must be four digits and the base year must be more recent. Backend validation also rejects identical source paths.
- Clients present in the base year remain in the report even when their amounts are zero.
- Missing products are reported even when the source group is empty. Existing products with an empty database group are offered for editing instead of incorrectly being labeled absent. Duplicate warnings across years are removed consistently.
- Bulk adding missing products no longer dismisses products with empty names as though they had been saved.
- File-drop changes are ignored while a report operation is running; failure to register the file-drop listener is surfaced.

## Remaining risks and limits

RustSec reports two transitive warnings from the GTK dependency chain:

- `delta -> tauri -> gtk -> glib 0.18.5`: [RUSTSEC-2024-0429](https://rustsec.org/advisories/RUSTSEC-2024-0429/), unsound `VariantStrIter` iterator implementation. The advisory identifies `glib >= 0.20.0` as patched; the GTK dependency requires the older series. Reachability of the affected iterator through Tauri/GTK was not established by this audit.
- `delta -> tauri -> gtk -> gtk3-macros -> proc-macro-error 1.0.4`: [RUSTSEC-2024-0370](https://rustsec.org/advisories/RUSTSEC-2024-0370/), unmaintained crate.

These warnings remain unresolved. This audit did not change the framework's GTK dependency series or suppress the advisories.

Checks ran on macOS. The browser UI used mocked desktop commands; native file dialogs, drag/drop integration, installed application startup, Windows/Linux builds, and signing/installers were not exercised end to end. The original business report workbooks referenced by `plan.md` were unavailable, so reporting tests used synthetic workbooks and the bundled reference spreadsheets. Existing user databases were not modified.

Passing these checks does not establish that the application has no remaining bugs.
